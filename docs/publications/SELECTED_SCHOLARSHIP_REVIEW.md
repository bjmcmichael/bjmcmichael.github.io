# Selected Scholarship Editorial Review

Status: **recommendations for editorial review only**

These recommendations are separate from topic membership. A publication may belong to a program without appearing in its compact Selected Scholarship module, and an overlapping publication may be recommended for more than one program when it materially represents both bodies of work. No recommendation in this document changes a public Research page.

The proposed sets favor a small, legible group of representative works; recency, disciplinary breadth, methodological breadth, and fit with each program's published description inform the proposed display order.
